What the tests prove

Pure rules reject invalid transitions, out-of-hours slots, non-half-hour slots, past slots and extreme timestamp input. Boundary tests cover the opening and closing of check-in and campus midnight.

SQLite integration tests exercise FIFO order, unique sequences for twenty concurrent visitors, duplicate joins, simultaneous operator calls, cancellation ownership, pause/reopen, terminal outcomes, database constraints, history persistence, session expiry and failure isolation for disconnected subscribers.

Booking integration tests exercise competing reservations, slot release, simultaneous-service restrictions, reservation caps, check-in ownership and timing, duplicate check-in, active-ticket conflicts, missed reservations and invalid services.

HTTP tests run the actual application with a temporary database. They cover public server-rendered pages, registration, cookie login, logout, operator routing, visitor restrictions, invalid credentials, antiforgery validation, password hashing, duplicate emails, public API privacy, health and 404 responses.

Manual acceptance checklist

Open Overview at a desktop width and verify all service cards and navigation are readable.
Open at a narrow mobile width and verify that the page has no horizontal overflow, except intended scroll containers.
Register an account and verify that private navigation shows the correct name.
Join a queue and verify My tickets and the overview show the same code.
Open a separate operator session, call that visitor and verify the student ticket changes without a reload.
Complete the visit and verify history and daily totals.
Join and cancel a waiting ticket, checking the confirmation step.
Reserve tomorrow's slot, cancel it and confirm it becomes selectable again.
Try an appointment check-in outside the permitted window and confirm it is unavailable.
Pause a service as operator and confirm a visitor cannot join it.
Open the public display and confirm no personal information appears.
Navigate using keyboard only and confirm the skip link, visible focus and form labels work.
Stop and restart the application and confirm visits remain saved.
Repeat the critical workflow in a second browser and record the result.
